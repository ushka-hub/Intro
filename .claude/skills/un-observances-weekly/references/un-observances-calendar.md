# UN International Days and Weeks: baseline calendar

This is a working copy of the UN list at https://www.un.org/en/observances/list-days-weeks, with the main SDGs for each day. It is a **fallback and a checklist**, not the final word: the UN adds new days most years. Always check the live UN list or a web search (see SKILL.md, Step 2), and add any new day here.

Floating dates are worked out for the current year. "SDGs" lists the most relevant goals, the main one first; confirm them against the official page.
