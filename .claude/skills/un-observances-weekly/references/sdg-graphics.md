# SDG graphics

Card 5 ("Why it matters") shows the SDG graphic for each goal. Gamma can only place images it can reach by **public URL**, so each SDG needs a link to Megan's graphic.

**To add Megan's graphics:** upload each image somewhere with a public link (for example a public Google Drive or Dropbox link, or commit the files to `sdg-graphics/` in this repo and use the raw GitHub URL if the repo is public), then replace `ASK ME` below with the URL.

Until a URL is filled in, the skill leaves a marked graphic space on card 5 and lists it in the ASK ME list.

UN rules for the icons: use each icon whole (number, title and graphic), don't change its colours or proportions, and include the disclaimer and a link to https://www.un.org/sustainabledevelopment/ (handled on the Sources card).
