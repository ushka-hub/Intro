# SDG graphics

Card 5 ("Why it matters") shows the official UN icon for each SDG. Gamma can only place images it can reach by **public URL**.

The URLs below are the **official UN SDG icons** (English, 2016 set from un.org/sustainabledevelopment), served from Wikimedia Commons, where the UN files are mirrored in the public domain. `Special:FilePath` is a stable link that redirects to the current file; `?width=800` asks for an 800px PNG.

**To swap in other graphics:** replace a URL below with any public image link (for example a public Google Drive or Dropbox link). Use `ASK ME` to leave a marked graphic space on card 5 instead.

If an icon doesn't show up in a generated Gamma, Megan can drop it in by hand: the official set is at https://www.un.org/sustainabledevelopment/news/communications-material/.

UN rules for the icons: use each icon whole (number, title and graphic), don't change its colours or proportions, and include the disclaimer and a link to https://www.un.org/sustainabledevelopment/ (handled on the Sources card).
